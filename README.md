# Agribank Chi nhánh Phú Thọ • Cổng Quản trị & Tiện ích Khai thác Hồ sơ

Hệ thống ứng dụng Web Portal dành cho **Agribank Chi nhánh Phú Thọ**, hỗ trợ bóc tách QR CCCD gắn chip, tự động lập hồ sơ Word/A4, quản lý danh mục mẫu biểu linh hoạt, kết nối máy in Bluetooth & phân quyền bảo mật cán bộ.

---

## 🌐 Hướng Dẫn Đưa Lên Cloud (Truy cập từ 4G/5G & Mọi Wi-Fi)

### Cách 1: Đưa lên Vercel (Khuyên dùng - 1 Phút có ngay đường link HTTPS)

1. Đăng ký/Đăng nhập tài khoản miễn phí tại **[https://vercel.com](https://vercel.com)** (Đăng nhập bằng Email hoặc GitHub).
2. Tải toàn bộ thư mục code dự án này lên Vercel bằng cách:
   - **Hoặc** kéo thả trực tiếp thư mục dự án vào giao diện Vercel Dashboard.
   - **Hoặc** dùng lệnh Vercel CLI trong terminal:
     ```bash
     npm i -g vercel
     vercel
     ```
3. Sau 30 giây, Vercel sẽ cung cấp đường link HTTPS miễn phí trực tuyến, ví dụ:
   `https://agribank-phutho.vercel.app`

---

### Cách 2: Đưa lên GitHub Pages (Miễn phí vĩnh viễn)

1. Tạo một repository mới trên GitHub (Ví dụ: `agribank-cccd-phutho`).
2. Tải toàn bộ mã nguồn lên repository đó.
3. Vào **Settings** ➡️ **Pages** ➡️ Chọn branch `main` ➡️ Save.
4. Đường link truy cập trực tuyến sẽ sẵn sàng tại:
   `https://<username>.github.io/agribank-cccd-phutho/`
